TRACEGUARD - FLASK + SQLITE VERSION

Technology:
- Frontend: HTML, CSS, Jinja
- Backend: Python Flask
- Database: SQLite (traceguard.db is created automatically)

HOW TO RUN ON WINDOWS / VS CODE
1. Extract this ZIP.
2. Open the TraceGuard_Flask folder in VS Code.
3. Open Terminal.
4. Run:  py -m pip install -r requirements.txt
5. Run:  py app.py
6. Open: http://127.0.0.1:5000

Records page: http://127.0.0.1:5000/records
Stop server: Ctrl + C
